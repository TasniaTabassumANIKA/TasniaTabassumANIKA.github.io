# Tasnia Tabassum Anika — Academic Website

Jekyll-based academic website intended for GitHub Pages.

## Repository name
Use:
`TasniaTabassumANIKA.github.io`

## Main sections
- Home
- Research
- Publications
- Education & Work
- Teaching
- Updates
- CV
- Contact

## Personalization
1. Add your portrait as `assets/img/profile.jpg` and replace the `.profile-fallback` in `index.md` with an `<img>` tag.
2. Add your latest CV as `assets/files/Tasnia_Tabassum_Anika_CV.pdf`.
3. Update `_data/*.yml` files whenever publications, projects, education, experience, or updates change.
